> **v1.8.0 亮点**：修复网盘存储统计并发竞态（150MB 文件被统计成 4MB 的根因，并提供存量数据一键重算）；聊天/网盘/语音全链路消灭静默失败（任何失败都给出原因与修复方式）；管理员**一键自检**系统 —— 12 项真实世界测试（真的走一遍建仓→上传→下载→比对→清理），故障项附一键修复动作 + 傻瓜化分步教程；配套终端医生 `bun scripts/doctor.mjs --key 超级密钥 --fix-all`。

## 这是什么

一套可以部署在自己服务器上的「加密聊天 + 隐私网盘」系统：

- **加密聊天频道** —— 频道 ID + 密码即房间；密码在浏览器本地派生 AES-256-GCM 密钥，消息、昵称、文件名全部端到端加密后才经服务器中继。支持文字 / 图片 / 视频 / 文件（可直接 Ctrl+V 粘贴上传）、回复（点击引用条跳转定位）、正在输入提示、在线设备一览（型号 / 系统 / 浏览器 / IP 归属地 + v1.7 心情状态）、任何成员可删除单条或清空频道。消息带 Telegram 式状态（转圈/送达单勾/已读双勾），支持 /readtip、/nick、/avatar、/mood、/p2p、/admin、/stats、/destroy 等快捷指令；v1.6 起支持表情回应、`||剧透||` 遮罩与 `/roll /coin /rps /decide /8ball` 频道玩具；v1.7 起新增 `/poll` 加密投票、`/ttt` 井字棋对战、⚡闪照（阅后即焚）与 `/confetti /fireworks` 全屏特效。
- **语音频道** —— Discord 风格的 P2P 语音开黑：WebRTC mesh + SRTP 加密，音频 P2P 直传不留存，含静音切换与说话指示。
- **私聊（whisper）** —— 点击他人头像发起频道内端到端私聊：服务器只定向投递不存储，用频道密钥加密；可一键加好友。
- **头像系统** —— 设备面板顶部上传图片，自动裁剪 256×256，加密后随 presence 广播；消息列表/设备面板/私聊面板自动渲染。
- **好友系统** —— 本地联系人列表（零服务器感知）；支持好友码 `频道ID::设备ID` 复制与导入；在线好友可一键发起私聊。
- **P2P 文字模式** —— 输入栏 P2P 开关按钮：双方都开启时优先走 WebRTC DataChannel 直传不留存，回退中继时仍加密留存。
- **管理员功能开关** —— 后台「功能」页签可独立开启/关闭「语音/私聊/好友/头像/P2P」五项功能。
- **隐私网盘** —— 随机 8 位 ID + 个人密钥解锁独立仓库；**创建仓库需管理员超级密钥**（首次使用时引导初始化，防止陌生人随意建仓占满硬盘）；单文件最大 5GB，分块流式加解密；文件名与元数据对服务器完全不可见。
- **自毁密钥** —— 紧急销毁开关：在任何密码输入处输入自毁密钥，立即销毁服务器上全部聊天与网盘数据（含磁盘密文、吊销全部会话），并向所有在线设备实时广播清屏。
- **实时同步** —— WebSocket 中继（消息 / 在线状态 / 输入状态 / 网盘多端同步 / 语音信令定向投递）。
- **界面** —— Apple 风格毛玻璃设计，明暗自适应，手机/平板/桌面全自适应。

## 安全模型

| 环节 | 实现 |
|------|------|
| 密钥派生 | PBKDF2-SHA256，310,000 轮，盐绑定频道/网盘 ID |
| 消息加密 | AES-256-GCM，每条消息独立 IV |
| 文件加密 | 4MiB 分块，每块独立 IV，AAD 绑定 `fileId:index` 防篡改/重排 |
| 认证 | 服务器仅存 PBKDF2 认证哈希与房间哈希 `SHA-256(频道+哈希)` |
| 会话令牌 | 32 字节随机，库中只存 SHA-256(token)，日志零输出 |
| 防滥用 | IP 限流（建仓 3/小时、ID 生成 12/小时、消息 30/10秒） |

**忘记密码 = 数据永久无法解密**（包括服务器管理员自己）——这是零知识设计的必然代价。

## 快速部署（Debian 12）

```bash
tar -xzf cipherchat-v1.6.0.tar.gz
cd cipherchat
sudo bash deploy/setup.sh
# 打开 http://服务器IP:2053/
```

非标端口部署（2053 对外 / 13000+13003 仅本机），与 80/443 上的 Reality 协议完全共存。
完整手把手教程见 **[安装教程.md](./安装教程.md)**。

## 本地开发

```bash
bun install
bun run db:push
bun run dev                 # Next.js :3000（自动）
cd mini-services/relay && bun run dev   # WebSocket :3003
# 经内置网关访问 :81
```

## 目录结构

```
├─ src/app/               # 页面与 API 路由（Next.js App Router）
│   └─ api/               # chat/* drive/* 会话·分块上传下载·历史
├─ src/lib/crypto.ts      # 客户端 AES-256-GCM / PBKDF2 核心
├─ src/lib/server/        # 会话认证·分块存储·UA 解析·IP 地理·限流
├─ src/store/             # Zustand 状态（chat / drive）
├─ src/components/        # home / chat / drive / common UI
├─ mini-services/relay/   # socket.io 实时中继服务
├─ prisma/schema.prisma   # SQLite 表结构
├─ deploy/                # setup.sh · systemd 单元 · Caddyfile · 备份/卸载
├─ scripts/               # E2E 加密验证脚本
└─ 安装教程.md             # 手把手部署文档
```

## v1.8 新功能

- **管理员一键自检** —— 后台新增「自检」页签：12 项检查一次跑完，其中包含**真实世界测试**（不是读状态，而是真的走一遍 网盘建仓→分块上传→完结→下载→逐字节比对→清理，真实写读磁盘、真实 HTTP 自调用、真实 TCP/Socket.IO 握手）。故障项附失败原因、一键修复动作、傻瓜化分步教程；报告可导出 JSON。检查项注册表式设计 —— 新增一项检查只需在 `CHECK_REGISTRY` 追加一个条目。
- **一键修复动作库** —— 重算网盘占用（修复历史统计坏数据 + 清理幽灵文件记录）、清理孤儿文件（上传中断残留）、整理数据库（VACUUM + WAL 合并）、清理/吊销会话、立即备份；后台「维护」页与自检失败项均可直达。
- **CLI 服务器医生** —— `bun scripts/doctor.mjs --key 超级密钥`（终端全量自检）、`--fix-all`（自动修复 + 复查）、`--recalc` / `--cleanup` / `--backup` / `--vacuum` 直连修复、`--json` 供脚本消费；密钥派生参数与网页端完全一致。
- **网盘存储统计修复** —— 修复 `dirSizeBytesAsync` 并发丢失更新竞态（150MB 文件统计成 4MB 的根因）；complete/delete 配额写库失败不再静默；配套「重算网盘占用」一键修复升级前已产生的坏数据。
- **全链路消灭静默失败** —— 统一错误翻译器（`src/lib/errors.ts`）把网络/HTTP/浏览器权限类失败翻译为「原因 + 处理方式」；覆盖加入频道、历史加载、WebSocket 断连、网盘解锁/上传/下载/预览/删除、语音播放/录音/TTS/TURN 全部失败路径。
- **TURN 短期凭证自动轮换** —— time-limited 模式 45 分钟自动换新（过期前 15 分钟），修复语音「突然全断且无提示」的隐患。
- **安全护栏** —— `deleteFileDir` 拒绝空/非法 fileId（防止误删整个 data/chat 或 data/drive 根目录）；信箱投递改为事务内原子容量检查。

## v1.6 新功能

- **表情回应 Reactions** —— 悬浮消息点笑脸/右键菜单回应常用 emoji（双击消息快速 👍），聚合计数、再点取消；回应密文链路与普通消息一致，服务端只存「谁对哪条消息点了什么」，不接触明文。

- **频道草稿箱** —— 未发送文本按频道本地暂存，刷新/切频道不丢。
- **未读标题提醒** —— 后台标签页显示 `(N)` 未读数；**引用跳转**点击引用条滚动高亮原消息。
- **屏幕安全模式** —— 菜单开启后切后台/失焦自动模糊消息区，防工位偷窥；Ctrl/Cmd+F 频道内搜索、Esc 取消。
- **稳定性与安全修复** —— 修复输入指示器卡死、轮换取消崩溃、语音信令全房间广播、全局自毁漏清表、离线 presence 泄露完整 IP、缺块文件拼出坏流等真实缺陷；历史解密并行化，`tsc` 严格模式零错误，50 个单元测试。

## v1.7 新功能

- **加密投票 `/poll`** —— 题目选项整体端到端加密，服务器只存「谁投了第几项」；实时计票条、可改票、旁听禁投。
- **井字棋对战 `/ttt <昵称>`** —— 发起者执 X 先手，点格子即可接招；走子广播、旧盘只读、胜负判定纯函数化并全量单测。
- **闪照（阅后即焚图片）** —— ⚡ 开关开启后发送：首个查看者开始下载即锁定，读完服务器**真实焚毁**磁盘密文与记录；第二个人看到「已焚毁」。
- **全屏特效 `/confetti` `/fireworks`** —— 全频道同屏彩带/烟花（纯 Canvas 实现，零依赖），庆祝时刻仪式感拉满。
- **心情状态 `/mood 🌙`** —— 心情随 presence 加密广播，成员面板昵称旁展示。
- **安全与性能大修** —— 修复跨频道已读回执泄露、IP 伪造绕限流（TRUST_PROXY 开关）、TURN 凭证公开下发、分块数×块大小磁盘填充绕过、取消轮换孤儿文件、邀请并发兑换超限等 15 项；全链路异步 I/O、细粒度 store 订阅 + memo 化、ack 超时与历史纪元守卫；单元测试 50 → 106 个。

## v1.4 新功能

- **TTS 文本朗读** —— 每条文字消息可一键朗读，另提供全局自动朗读开关；浏览器原生 SpeechSynthesis 实现，零延迟、文本不出设备（无障碍场景友好）。
- **二维码邀请链接** —— 双模式分享：①「免密钥令牌」频道密钥经服务器主密钥 AES-256-GCM 二次加密后保管，URL 仅含随机短码，对方扫码即自动加入；②「仅频道 ID」对方打开分享页后需手动输入密钥。均可设置有效期与使用次数上限。
- **语音大厅文字副频道** —— 开黑时没麦/不想说话的成员可在右侧滑出侧栏文字聊天；消息同样经大厅密钥端到端加密，服务器只转发不存储。
- **屏幕共享** —— 语音大厅内一键 `getDisplayMedia` 共享屏幕，视频轨注入全部 WebRTC 连接并自动重协商；对方可在浮动窗口观看。
- **密钥轮换** —— 4 阶段安全协议（start→migrate→files→finish）：更换密码时消息与文件全部在客户端解密后用新密钥重加密，无缝迁移；旧会话吊销、旧密码即刻失效。含幂等保护、失败标记与取消回滚。
- **独立已读回执** —— 每条消息底部独立显示 发送中→已送达→已读 状态，连发多条不再只显示一个对勾。
