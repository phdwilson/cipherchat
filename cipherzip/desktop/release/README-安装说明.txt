CipherZip 密匣 v1.0.0 — Windows 11 安装包
========================================

推荐文件：
  CipherZip-Win11-安装包-1.0.0.exe     （便携/自解压，双击即用，无需安装）
  CipherZip-Portable-1.0.0.exe         （同上）
  CipherZip-Setup-1.0.0-x64.zip        （解压后运行「CipherZip密匣.exe」）

使用：
  1. 双击 .exe 或解压 zip
  2. 首次建议在「压缩加密」中使用 .ccz 格式并设置强密码
  3. 可选：在「密钥文件」中选择一首音乐作为第二因子
  4. 「端到端互连」可生成分享码与好友 P2P 聊天/传文件
  5. 「密讯联动」填写 CipherChat 网址即可对接网页后端

可选增强：
  安装 7-Zip 后可更好支持 rar/7z 等格式。

源码与模块化升级：
  见仓库根目录 README.md
