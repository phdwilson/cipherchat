CipherZip 密匣 — Windows 11 安装说明
================================

方式 A：NSIS 安装包（推荐）
  运行 CipherZip-Setup-*-x64.exe，按向导选择安装目录，创建开始菜单与桌面快捷方式。

方式 B：便携版
  解压 CipherZip-Portable-*.exe 或 zip 到任意目录，运行 CipherZip密匣.exe。

方式 C：开发者布局（本目录）
  1. 安装 Node.js 18+ 与 Electron 依赖（见仓库 README）
  2. 在仓库根目录执行 npm install && npm run build:core
  3. cd cipherzip/desktop && npx electron .

系统要求：Windows 10/11 x64。可选安装 7-Zip 以增强 rar/7z 支持。
